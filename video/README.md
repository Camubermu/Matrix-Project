Los videos propios van aquí, en .mp4.

Referéncialos desde content-es.js con:
  { type: 'video', h: 'Título del video', src: 'video/mi-video.mp4' }

Para YouTube no necesitas subir nada:
  { type: 'video', h: 'Título del video', yt: 'ID_DEL_VIDEO' }

GitHub no es buen host para archivos grandes. Arriba de ~25 MB, usa YouTube.
